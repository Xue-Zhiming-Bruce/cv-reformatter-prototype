# Historical Pipeline Documentation

A-D, C2/DOCX, and E1-E4 experiment runners, compatibility imports, and their
exclusive tests were retired on October 19, 2026. Their source remains in Git.

The retained implementation runs through `python -m app.pipeline` with explicit
inputs; see the repository [README](../../README.md). Applicable regressions
and synthetic fixtures now live in the canonical locations described in
[tests/README.md](../README.md).

This directory retains historical plans and curated reports pending the
documentation cleanup. Commands in those reports describe past runs and are
not current entry points. Ignored local runs and input data were not deleted.
