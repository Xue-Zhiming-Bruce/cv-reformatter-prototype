## 关键新发现（根因假设，测量依据）

渲染行宽 = 580.2 − 46.19 = **534.0pt**；F 自身设计行宽 = 570.60 − 46.8 =
**523.8pt**——渲染行比 F 设计**宽 10.2pt**（≈ 一倍缩进）。F 自身行右缘
570.6 = 46.8 + 523.8，与其设计自洽。假设：**种子模板生成层（b_pipeline
`_seed_template`，Adobe 实测链）为 F 派生的行盒宽度比 F 实际设计宽约
10.2pt**（很可能把 F 的缩进既算进盒位置又算进盒宽度，或对 margin/padding
双重计入）。若成立，则右缘超界是**种子宽度缺陷的下游症状**，任何 margin/
padding 旋钮都只能在错误宽度上打补丁——这解释了四连杠杆的阻尼与无效。
